# StockTrendML 📊  
**Indian Stock Analysis & Prediction Tool**  

![Python](https://img.shields.io/badge/Python-3.8+-blue) 
![License](https://img.shields.io/badge/License-MIT-green)

## Features  
- Real-time NSE/BSE stock data (e.g., `RELIANCE.NS`)  
- Technical charts (RSI, MACD, Bollinger Bands)  
- Price prediction for next 15-90 days  
- Simple investment calculator
