## 🌟 Key Features  
- **Real-time NSE/BSE Data** (e.g., `RELIANCE.NS`, `TCS.NS`)  
- **Technical Indicators**: RSI, MACD, Bollinger Bands  
- **Price Prediction**: Linear regression forecasting (15-90 days)  
- **Interactive Charts**: Zoomable Plotly visualizations  
- **Investment Calculator**: Future value projections
