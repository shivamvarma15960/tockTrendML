# 📈 StockTrendML  
**AI-Powered Stock Analysis & Prediction Dashboard**  

![Python](https://img.shields.io/badge/Python-3.8+-blue) 
![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?logo=streamlit&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)


## 🌟 Key Features  
- **Real-time NSE/BSE Data** (e.g., `RELIANCE.NS`, `TCS.NS`)  
- **Technical Indicators**: RSI, MACD, Bollinger Bands  
- **Price Prediction**: Linear regression forecasting (15-90 days)  
- **Interactive Charts**: Zoomable Plotly visualizations  
- **Investment Calculator**: Future value projections
